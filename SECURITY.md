# Security Policy

## Reporting Security Issues

If you discover a security vulnerability or safety issue in Skarp, please report it responsibly:

- **Email:** Send details to [bagomwaraphael@gmail.com](mailto:bagomwaraphael@gmail.com).
- **GitHub:** If appropriate, you can open an issue on [GitHub Issues](https://github.com/realmadede/Skarp/issues).

Please include:
- A description of the issue.
- Steps or a script to reproduce the behavior safely.
- Any suggested mitigations or patches.

We appreciate your responsible disclosure and will review reports promptly.
